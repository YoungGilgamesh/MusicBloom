# MusicBloom

An audio-reactive Three.js flythrough. Cover attract mode, Start into a painted particle cloud, then an ending still that loops back.

## Run

```bash
npm install
npm run dev
```

Serve over http(s). Do not open the built files as `file://`.

```bash
npm run build
npm run preview
```

Host the `dist/` folder.
